# Espoo Bike Fix

Single-file static demo website for Espoo Bike Fix, a bicycle repair and service shop in the Kilo area of Espoo (Vieraskuja 5, 02770 Espoo).

## How to open

Double-click `index.html` in a browser, or serve the folder with any static server, for example `npx serve .` or `python -m http.server`.

## Details

- Everything is in one file: HTML, CSS and JavaScript, no build step.
- Only external requests are Google Fonts (Archivo) and photos from images.unsplash.com.
- Demo website.
